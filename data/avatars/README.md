# Портреты персонажей из комплекта

PNG или WebP (лучше WebP — в 5–10 раз меньше), можно с прозрачным фоном, квадрат 512×512, лицо/фигура по центру,
имя файла — id (расширение .png, .webp или .jpg):

dewiar.png  patrik.png  agent.png  jarvis.png  lira.png  eva.png                     — команда
professor.png  femida.png  doctor.png  iris.png  oskar.png  gaston.png  nika.png  mishel.png — галерея

Если файл есть — персонаж показывается портретом (в виджете, студии и галерее). Свой портрет пользователя
(«Изменить» → фото) важнее портрета из комплекта.
