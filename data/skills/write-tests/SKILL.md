---
name: write-tests
description: Написать тесты для кода проекта — модульные, для функции, модуля или исправленной ошибки. Когда просят «напиши тесты», «покрой тестами».
---
Веди фоновой задачей (start_task с project).

1. Найди, чем проект уже тестируется: pytest/unittest, jest/vitest, go test, cargo test… (code_search, конфиги).
   Используй тот же фреймворк и ту же структуру папок. Нет тестов — для Python возьми pytest, для JS — то, что
   уже есть в package.json, иначе node:test.
2. Прочитай тестируемый код. Проверяй поведение, а не реализацию: обычный случай, граничные значения, ошибки.
3. Тесты должны быть быстрыми и независимыми: без сети, без реальных файлов пользователя (временные папки).
4. Запусти (code_run) и добейся, чтобы новые тесты проходили. Если тест выявил настоящую ошибку в коде —
   не подгоняй тест, а напиши об этом в итоге (и предложи исправить).
5. finish: какие тесты добавлены, что покрыто, команда для запуска.
