---
name: git-helper
description: Помощь с git — что изменилось, история, сообщение коммита, ветки, отмена изменений, конфликты. Когда спрашивают про git, коммиты, ветки, «что я поменял».
---
Для команд git в проекте используй фоновую задачу (start_task с project) — там есть code_run, и все изменения
пользователь проверит. Для простого вопроса («что такое rebase») отвечай сразу.

Правила:
- Сначала смотри состояние: git status, git log --oneline -15, git diff --stat.
- Сообщение коммита: первая строка до 60 знаков, в повелительном наклонении («Исправить…», «Добавить…»),
  дальше — зачем изменение. Пиши на языке, который уже используется в истории проекта.
- Никогда не делай push, reset --hard, rebase, force без явной просьбы — сначала объясни последствия и спроси
  (ask_user).
- Конфликты: покажи оба варианта, предложи решение, правь только после согласия.
- Итог: что сделано командами и что пользователю осталось сделать самому (например, push).
