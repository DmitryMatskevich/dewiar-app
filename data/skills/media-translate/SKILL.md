# Перевод видео для OpenMontage

Используй навык, когда пользователь просит «переведи ролик», «переведи видео», «с английского на русский» или «с русского на английский».

1. Получи источник: ссылку YouTube/поддерживаемого видеосервиса или выбранный локальный файл.
2. Сначала используй доступные субтитры. Если их нет, извлеки аудио и распознай речь: для русского — GigaAM, для английского/неизвестного языка — `mlx-whisper` при наличии.
3. Сохрани оригинальные TXT/SRT и чистовой Markdown отдельно от перевода.
4. Подготовь литературный перевод, целевые SRT-субтитры, сценарий озвучки и `openmontage.json`.
5. Оставь в manifest этапы выбора голоса, проверки экранного текста и аудио как `pending`.

Дубляж, монтаж, рендер и публикация не запускаются автоматически. Для повторного запуска используй готовые результаты и не скачивай источник заново без необходимости.
