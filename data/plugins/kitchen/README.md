# 🍳 Кухня

Рецепт из того, что есть дома, таймеры по шагам и список покупок.

Скажите, что лежит в холодильнике, — Лира предложит пару блюд и поведёт по рецепту шаг за шагом: на каждом шаге, где нужно ждать, сама поставит таймер. Чего не хватает — допишет в заметку «Покупки».

## Что говорить

- «Что приготовить из курицы, риса и кабачка?»
- «Веди меня по рецепту сырников»
- «Следующий шаг»
- «Добавь в покупки сметану и укроп»
- «Что у меня в покупках?»

## Настройки

- **Особенности питания** — например, без глютена, вегетарианское, без орехов…
- **Обычно готовлю на**
- **Сложность**

## Дела по расписанию (включаются по желанию)

- Меню на неделю — по воскресеньям в 10:00

## Что использует

Навык: kitchen-helper. Инструменты: set_reminder, save_note, find_notes, web_search. Ничего дополнительно ставить не нужно.
