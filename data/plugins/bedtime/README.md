# 🌙 Сказка на ночь

Сказка с именем ребёнка, тихим голосом — и сама затихнет.

Добрая сказка, где герой — ваш ребёнок, его любимые игрушки и звери. Короткая, спокойная, с мягким концом. Можно продолжать вчерашнюю историю — Лира запомнит, на чём остановились.

## Что говорить

- «Расскажи сказку на ночь»
- «Сказку про дракона, который боялся темноты»
- «Продолжи вчерашнюю сказку»
- «Сказку покороче — уже засыпаем»

## Настройки

- **Имя ребёнка** — например, Маша
- **Возраст**
- **Что любит** — например, динозавры, кот Барсик, космос

## Дела по расписанию (включаются по желанию)

- нет

## Что использует

Навык: bedtime-story. Инструменты: save_note, find_notes. Ничего дополнительно ставить не нужно.
