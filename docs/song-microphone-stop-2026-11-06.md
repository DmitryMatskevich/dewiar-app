# Запись песни с микрофона: остановка и восстановление

Причина: остановка находилась в свёрнутых свойствах карточки; цикл захвата бесконечно продолжался при пустых пакетах. Завершение записи, возврат голосового ввода и запуск анализа выполнялись только командой страницы. Исключение чтения закрывало устройство, но оставляло карточку в состоянии записи.

Изменения:

- Видимая кнопка «Остановить запись» в списке и над этапами открытой карточки. Повторное нажатие безопасно; ошибка оставляет возможность повторить.
- Для микрофона: остановка после пяти секунд непрерывной тишины (энергия PCM ниже примерно −50 dBFS). Музыкальный проигрыш со звуком продолжает записываться. Постоянный шум выше порога требует ручного стопа.
- Для обоих входов: остановка после пяти секунд отсутствия пакетов, обработка исключения устройства, предельная длительность 10 минут. Контроллер не блокируется в чтении аудиодрайвера. Если сам драйвер завис при закрытии, интерфейс сообщает об ожидании освобождения устройства и запрещает второй конкурирующий захват.
- Единое завершение сохраняет WAV, освобождает вход, возвращает прежнее состояние голосового ввода и один раз запускает полный разбор. При выходе запись остаётся в очереди до следующего старта; при ошибке планировщика остаётся доступна кнопка продолжения.
- Заголовок WAV обновляется по мере записи. После аварийного выхода старые PCM-записи с недописанным заголовком восстанавливаются в новый файл без изменения исходного. Пустые/короткие записи не отправляются в распознавание и минусовку.

Проверка: 17 модульных сценариев (2 базовых, 3 управления голосовым вводом, 12 жизненного цикла) и две проверки веб-интерфейса. Проверены карточки с сокращёнными серверными данными, остановка после закрытия редактора, ожидание ответа, повтор после ошибки и ширины 390/760/1100 px. Для нового поведения использован синтетический PCM; физический микрофон пользователя для теста не включался.

Перед обновлением проверена настоящая карточка «Когда стану бабкой янтарная»: статус `review`, ревизия 35, WAV 310208 мс; активных записей нет. Файл и метаданные сохранены, повторное распознавание этой карточки не запускалось.

Сборка основана на установленном приложении с шестью изменёнными файлами этой задачи; остальные незавершённые изменения рабочего дерева не включены. Проверка миграции на временной копии настроек: LLM/STT/TTS совпадают. Артефакты сборки, контрольные суммы и проверки: `work/song-microphone-stop-20261106/`.
