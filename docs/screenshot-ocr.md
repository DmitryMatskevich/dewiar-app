# Снимок экрана и локальный OCR

Команды: «Снимок экрана», «Лира, снимок экрана», «Скриншот», варианты со словом «Сделай», «Сфотографируй экран».
Распознаются как самостоятельные команды. Вопрос «Как сделать снимок экрана?» ничего не снимает.
Дополнительные поручения («и отправь Ивану») остаются обычным запросом агента с его проверками доступа.

## Что повторно использовано

Проверены существующие исходники на этом Mac:

- OpenMontage `projects/lan-fobm-rm-6p-localization/scripts/audit_text.swift` и
  `projects/lan-fms-tatiana-narration/scripts/audit_every_frame.swift`: Apple Vision,
  `VNRecognizeTextRequest`, `.accurate`, `ru-RU` + `en-US`, `usesLanguageCorrection=false`,
  текст, confidence и нормализованные bounding boxes. В Dewiar используется тот же API через PyObjC,
  без запуска видеопайплайна, Swift-компилятора или зависимости от рабочего каталога OpenMontage.
- OpenMontage `projects/lanmaster-english-batch-20261025/audit_text.py` и
  `projects/lan-pcext-u5e-english/scripts/ocr.py`: резервный Tesseract с `rus+eng`.
  Существующий `rus.traineddata` из `cbwpg-audit4/tessdata` повторно использован локально.
  Установщик копирует реальные данные, включая цель старой ссылки `eng.traineddata`, в собственную папку Dewiar.
  Он сохраняет SHA-256 и источник в локальном manifest.json. Старый проект после этого не требуется.

Для экранов не перенесён порог minimumTextHeight 0.012/0.014 из аудита видеотитров:
он мог бы отбросить мелкий текст интерфейса. Не перенесены ffmpeg, удаление титров, перевод, TTS и монтаж.
При резервном OCR используется автоматический разбор страницы Tesseract PSM 3, подходящий всему экрану.

## Устройство

Кнопка снимка рядом с полем ввода также сохраняет документ в «Заметки → Снимки экрана»
и запускает локальный OCR. В сообщение добавляется тот же снимок (JPEG-превью),
а в заметке остаётся исходный PNG и полный распознанный текст. До отправки сообщения
ничего не передаётся модели. Значок заметок подсвечивается и показывает точку;
нажатие открывает новую запись. Кнопка учитывает запрет снимков в настройках Dewiar.
Панель ввода сохраняет одну строку кнопок: при уменьшении окна сокращается название
модели и длина индикатора микрофона, действия очистки/копирования/отправки не переносятся.

1. `CommandsMixin._screenshot_cmd` перехватывает явную локальную команду до LLM; проверяет политику
   `save_screenshot`, при необходимости запрашивает подтверждение, выполняет работу в отдельном потоке.
2. `macsys._screenshot_without_dewiar` получает основной дисплей через ScreenCaptureKit и фильтрует окна
   Dewiar по bundle id, pid локальной оболочки или точным служебным заголовкам. Не исключает все окна Python.
   Снимок сохраняет исходное разрешение. Если исключение недоступно, захват с ассистентом не подставляется.
3. `screen_document.create` сохраняет Markdown и PNG до OCR. Файл заметки обновляется атомарно.
   Имена содержат время и случайный суффикс; предыдущие снимки не затираются.
4. `ocr.recognize_result` запускает Vision, затем при необходимости Tesseract. Отсутствие языкового пакета
   не считается успешным распознаванием. Используется полный текст без прежнего лимита 6000 символов.
   В собранной macOS `.app` Vision выполняется отдельным процессом `--ocr-worker`:
   PNG передаётся через stdin, JSON возвращается через stdout, без модели и сети.
   Предел ожидания — 25 секунд, затем используется резервный Tesseract. Это отделяет
   нативный OCR от длительно работающего многопоточного ядра. В оконной сборке
   используются файловые дескрипторы каналов, поскольку `sys.stdin/stdout` могут быть `None`.
5. Текст сохраняется буквально в блоке кода. TXT удобен для копирования; OCR.json хранит движок, статус,
   размеры изображения и координаты/уверенность строк Vision. У Tesseract в этом режиме координат нет.
6. `note_saved` обновляет заметки, уведомление с кнопкой открытия и точку на кнопке «Заметки» HUD.
   Повторные события одного пути при двух этапах OCR не увеличивают число новых заметок. Индикатор хранится
   в памяти окна в текущем сеансе. Нажатие открывает последнюю новую запись; `notes_seen` из студии или
   успешное открытие через уведомление снимает отметку. При ошибке открытия отметка остаётся.
   Сохранение и OCR не открывают сеть,
   не отправляют снимок модели и не зависят от доступности подписки.

Остановка отменяет дальнейший OCR перед его запуском и подавляет запоздалый ответ агента. Уже выполняющийся
системный запрос Vision завершается самостоятельно; готовые файлы сохраняются. Одновременный повторный захват
отклоняется. Если процесс прерван во время OCR, снимок и документ первого этапа остаются, автоматического
возобновления OCR после перезапуска пока нет.

## Зависимости и повторное использование языковых пакетов

Перед первым снимком: «Безопасность → Доступы macOS» или верхнее меню «Агент Dewiar → Доступы macOS».
Страница подготовки открывается один раз после обновления; опционально — при каждом запуске.
Запросы экрана и папок запускаются отдельными кнопками, без начала записи, чтения документов или смены
рабочей папки. Кнопка папки проверяет доступ из ядра; «Проверить доступы» показывает последний результат
для файлов и свежие статусы экрана/микрофона. macOS может потребовать перезапуск после выдачи прав экрану.

Для Mac: `pyobjc-framework-ScreenCaptureKit`, `pyobjc-framework-Vision`, Pillow; macOS 14+.
ScreenCaptureKit включён в список скрытых импортов PyInstaller. Vision не требует отдельной модели.
Tesseract — необязательный резерв; его исполняемый файл должен быть установлен.

```bash
.venv/bin/python tools/install_ocr_languages.py --source /папка/с/rus-и-eng-traineddata
```

Каталог назначения: `STATE_DIR/models/ocr/tessdata`. Можно явно указать `--destination`.
При чтении OCR проверяет `DEWIAR_TESSDATA_DIR`, собственный каталог моделей, затем `data/ocr/tessdata`.
Если подходящего каталога нет, используются стандартные модели установленного Tesseract.
Данные старого проекта и его абсолютный путь не зашиты в исполняемый код Dewiar.

## Проверки

- `tests/screen_document_test.py`: два этапа, реальные файлы и вложения, полный текст, отсутствие перезаписи,
  отказ в доступе, пустой OCR/ошибки, отмена, параллельный запрос, русский и английский через реальные Vision
  и резервный Tesseract с повторно использованными языковыми пакетами.
- `tests/screen_command_test.py`: выполнение без LLM, запрет, подтверждение/отказ, ошибка, остановка,
  отсутствие позднего ответа.
- `tests/screen_document_ui_test.py`: чтение документа, PNG/TXT, буквальный код/Markdown и Help.
- `tests/notes_badge_ui_test.py`: точка новых заметок, подсказка, отсутствие дублей OCR, снятие отметки
  после чтения, сохранение отметки при ошибке открытия, границы индикатора в светлой/тёмной теме.
- `tests/screenshot_button_ui_test.py`: настоящее нажатие в HUD через обработчик команды,
  реальные файлы заметки, PNG и TXT, две фазы одного документа без двух индикаторов,
  вложение того же изображения, открытие записи, запрет захвата при отключённом инструменте.
- `tests/hud_draft_actions_ui_test.py`: все кнопки панели в одной строке без пересечений,
  длинное имя модели, диктовка и остановка ответа, ширины 340–900 px, светлая/тёмная тема.
- `tests/macos_screen_exclusion_probe.py`: ручная проверка на разблокированном Mac с двумя временными окнами:
  обычный снимок видит верхнее окно «Dewiar», отфильтрованный — нижнее окно другого цвета.
  Полный снимок рабочего стола этот тест не сохраняет.

Apple API: [SCScreenshotManager](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager),
[распознавание текста Vision](https://developer.apple.com/documentation/vision/recognizing-text-in-images).
