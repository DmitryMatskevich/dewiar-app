# Снимок экрана как сообщение ассистента

Сценарий обновлён 1 ноября 2026 года: снимок является результатом работы ассистента,
а не вложением пользователя. Автоматического добавления в заметки нет.

## Пользовательский сценарий

1. Нажать кнопку снимка в поле ввода или сказать «Лира, снимок экрана».
2. Dewiar снимает основной экран без своих окон, сохраняет оригинальный PNG
   во «Входящие/Снимки экрана» и распознаёт текст локально.
3. Результат появляется отдельным сообщением ассистента в HUD и в разделе «Чат».
   Карточка содержит изображение и кнопки действий. Строк «Распознанный текст»
   и «Текст распознан локально» в ней нет:
   - крестик — убрать сообщение из видимой переписки;
   - копировать картинку — записать исходный PNG в буфер обмена;
   - текст — появляется только при наличии текста; открывает модальный редактор
     с полным текстом, кнопками «Скопировать», «Сохранить» и «Закрыть»;
   - в заметки — создать заметку с картинкой и распознанным текстом.
4. Только последнее действие вызывает `note_saved` и подсветку значка заметок.
   Повторное действие возвращает ту же заметку, не создавая дубль.

Правки текста автоматически записываются в историю снимка после короткой паузы.
Копирование и закрытие дожидаются записи; при ошибке сохранения редактор остаётся
открытым с набранным текстом. Версия текста защищает от перезаписи более новых
правок из другого окна. Перенос в заметки использует актуальную сохранённую версию;
ранее созданная заметка остаётся самостоятельным документом.

Крестик сохраняет исходные данные и помечает сообщение скрытым. Уже созданная заметка
не удаляется. Картинки и OCR-текст не отправляются языковой модели автоматически.
Старые заметки, созданные предыдущим сценарием, не изменяются.

## Устройство

- `core/screenshot_messages.py`: захват, OCR, создание assistant-сообщения с вложением,
  получение оригинального PNG, явный перенос в заметки и скрытие сообщения.
- `core/chatlog.py`: сообщение и полный OCR сохраняются в журнале переписки;
  путь созданной заметки и признак скрытия переживают перезапуск.
- `ui/assets/screenshot-card.js` и `.css`: общая карточка HUD и студии. OCR выводится
  через `textContent`; кнопки имеют подписи доступности, состояние выполнения и ошибки.
- HUD загружает карточки текущей переписки после подключения и её изменения.
- `macsys.copy_image_data` и мост `macshell`: запись настоящих PNG-данных в NSPasteboard.
  Для браузера предусмотрен ClipboardItem; при отсутствии поддержки показывается ошибка,
  вместо выдачи ссылки или строки data URL за скопированную картинку.
- Перенос в заметки копирует исходный PNG и полный текст в Markdown/TXT.
  OCR внутри Markdown помещается в буквальный блок кода с безопасной длиной ограждения.

Проверяется политика `save_screenshot`. Режим Mac без голосового ввода сохраняет
возможность захвата реального рабочего стола; сервер без рабочего стола — нет.
Системное разрешение macOS проверяется реальным API. Установленное приложение:
`/Applications/Dewiar.app`. Особенности ad-hoc подписи и восстановления разрешений
описаны в [инструкции установки](macos-screen-permission-install.md).

## OCR

Сначала используется Apple Vision: accurate, ru-RU + en-US, без исправления слов
и без обрезки полного текста. В собранной macOS .app запрос выполняется в отдельном
процессе `--ocr-worker`: PNG через stdin, JSON через stdout. Предел ожидания — 25 секунд,
затем используется резервный Tesseract. Оконная сборка работает с файловыми дескрипторами,
поскольку `sys.stdin/stdout` могут быть `None`.

Tesseract использует rus+eng и собственные данные из `STATE_DIR/models/ocr/tessdata`.
Существующие языковые пакеты из проектов OpenMontage повторно использованы через
`tools/install_ocr_languages.py`; старые проектные пути не нужны приложению.
Отсутствующий языковой пакет не считается успешным распознаванием.
Если OCR не сработал, картинка остаётся в сообщении; копирование текста недоступно.

`core/screen_document.create` остаётся низкоуровневой утилитой прямого создания
документа для отдельных вызовов и тестов. Пользовательские снимки через движок
используют сообщения и явную кнопку переноса.

## Проверки

- `tests/screenshot_button_ui_test.py`: реальное нажатие через команду ядра,
  assistant-сообщение, отсутствие автоматической заметки, все четыре действия,
  полный текст, тот же PNG, идемпотентность переноса, восстановление после перезапуска,
  скрытие сообщения без удаления заметки, светлая/тёмная тема и ширины 340–640 px.
- `tests/macos_windows_test.py`: настоящий private pasteboard, запись PNG и чтение тех же байтов.
- `tests/screen_document_test.py`: реальный Vision/Tesseract, длинный текст, ошибки и тайм-аут worker.
- `tests/screen_command_test.py`: самостоятельные голосовые команды, запрет, подтверждение и отмена.
- `tests/notes_badge_ui_test.py`: индикатор заметок после ручного переноса и подтверждение чтения.
- `tests/hud_draft_actions_ui_test.py`: одна строка кнопок при длинном имени модели,
  диктовке и остановке, ширины 340–900 px.
