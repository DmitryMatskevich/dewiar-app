# Единый шаблон окон помощи и сообщений

Справка HUD, справка Студии, подтверждения и информационные сообщения используют `ui/assets/dialog.js` и `ui/assets/dialog.css`. Новые окна этих типов должны использовать этот шаблон, без собственной оболочки и отдельных правил цветов.

- `messagePopup(text, {title, steps, note})` — сообщение с копированием текста и кнопкой «Понятно».
- `ask(text, {title, ok, danger})` — подтверждение действия; `askText(text, value, options)` — текстовый ввод.
- `DewiarDialogs.mount({title, content, persistent, copyText, onClose})` — справка с собственным содержимым. `content` — локально созданный DOM-узел; внешние данные добавляются через `textContent` или экранирование. Добавьте действие через `view.addAction(...)`, открывайте `view.show()`, закрывайте `view.close()`.

Оболочка отвечает за нативный модальный слой, парные цвета фона и текста, неподвижные заголовок и кнопки, прокрутку содержимого, Escape, цикл Tab и возврат фокуса. Стили конкретной справки оформляют только её содержимое. Для существующего `<dialog>` передайте `root`; для повторного использования — `persistent: true`.

Проверки: `tests/unified_help_ui_test.py`, `tests/context_help_test.py`, `tests/dialogs1021_test.py`.
