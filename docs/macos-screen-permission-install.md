# Снимок экрана: установленная сборка и разрешения macOS

## Проверка 1 ноября 2026 года

Наблюдалось: в macOS включена запись экрана для Dewiar, но реальный
`CGPreflightScreenCaptureAccess()` возвращал отказ и кнопка снимка показывала ошибку.
Сборка запускалась из `app/dist/Dewiar.app`, подпись — ad hoc, bundle id —
`pro.dewiar.macos`, designated requirement привязан к cdhash. Действительных
сертификатов `security find-identity -v -p codesigning` не обнаружено.

Обычный перезапуск и выключение/включение переключателя записи экрана не помогли.
После закрытия окна оставались отдельные процессы `--core --server`.

Выполнено:

1. Закрыто приложение и завершены процессы ядра именно этой .app.
2. Текущая проверенная сборка скопирована в `/Applications/Dewiar.app`.
3. В настройках macOS удалена старая запись Dewiar из списка записи экрана
   и добавлен `/Applications/Dewiar.app`.
4. Запущена установленная копия. Кнопка «Приложить снимок экрана» создала
   реальное вложение с миниатюрой. Сообщение и снимок в модель не отправлялись.

Это подтверждает восстановление захвата у текущей сборки. Отдельно влияние пути
и повторной регистрации не измерялось: сами по себе приложения вне Applications
не запрещены macOS.

## Последующие обновления

Использовать `tools/rebuild_mac_app.command`: после сборки и проверки он
устанавливает приложение в `/Applications/Dewiar.app` и запускает эту копию.
Установщик `tools/install_mac_app.py` проверяет bundle id и подпись, не заменяет
запущенные копии, предварительно копирует и проверяет новую сборку, сохраняет
предыдущую версию и возвращает её при ошибке финального переименования.
Файлы приложения заменяются целиком, пользовательские данные не перезаписываются.

Для установки уже готовой сборки после полного завершения Dewiar:

```sh
.venv/bin/python tools/install_mac_app.py
```

Установщик не сбрасывает TCC и не выдаёт системные разрешения автоматически.
При смене ad-hoc идентичности он предупреждает о возможном повторном разрешении;
смена постоянной идентичности требует отдельного решения и останавливает установку.

Постоянный путь не гарантирует сохранение разрешений после пересборки с ad hoc.
Для этого нужна постоянная Apple Development / Developer ID Application подпись:
см. [подготовку подписи](macos-microphone-signing.md). Сертификат сейчас отсутствует;
сохранение разрешений между разными сборками пока не подтверждено.

Если переключатель включён, но текущая сборка всё ещё получает отказ, после
полного завершения приложения удалите только запись Dewiar в «Запись экрана»,
добавьте установленную копию и запустите её снова. Другие приложения не затрагивать.

Проверки установщика: `tests/macos_install_test.py` — полная замена без устаревших
файлов, резервная копия, откат при ошибке замены, запрет понижения постоянной подписи.
