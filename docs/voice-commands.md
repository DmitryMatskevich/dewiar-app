# Голосовые команды

Студия → «Руки» → вкладка «Голосовые команды». Настройки общие для всех персонажей.

Встроены действия открытия, штатного закрытия, сворачивания, переключения на приложение, включения/выключения «Не беспокоить» на Mac и поиска песни в Яндекс Музыке. У каждого действия редактируемые фразы (одна на строку) и выключатель. `{приложение}` заменяется названием программы, `{запрос}` — названием песни. Для фокусировки указываются цельные фразы без подстановок. Это буквальные шаблоны, не регулярные выражения и не команды терминала. Добавление новых типов действий требует реализации в ядре.

Стандартные команды открытия:

| Фраза | Приложение |
| --- | --- |
| «Открой таблицу», «Открой таблица» | Numbers (`com.apple.iWork.Numbers`) |
| «Открой офис» | LibreOffice (`org.libreoffice.script`) |
| «Открой почту», «Открой mail» | Mail (`com.apple.mail`) |
| «Открой контакты», «Открой контакт» | Contacts (`com.apple.AddressBook`) |

Программа должна быть установлена. Если Numbers отсутствует, Dewiar сообщает об этом; другая программа не выбирается вместо неё молча. Открытие Contacts не импортирует адресную книгу и не создаёт карточку. Присутствие слова в длинном поручении не означает команду открытия: «открой таблицу из файла» остаётся отдельной задачей.

## Фокусировка «Не беспокоить»

«Не беспокоить» и «переговоры» включают системную фокусировку до её выключения. «Выключи не беспокоить» выключает её. Повторное включение не переключает режим обратно. «Запланируй переговоры завтра» не включает фокусировку, поскольку это не точное совпадение команды. Действие не включает запись встречи и не меняет звук или микрофон Dewiar.

Для выполнения используется штатная утилита macOS `shortcuts` и две команды приложения «Команды». На текущем Mac они созданы. Для другого Mac нужна однократная настройка:

1. В «Командах» создать `Dewiar — Не беспокоить — Вкл`.
2. Добавить действие `Set Focus` (название зависит от языка macOS), выбрать именно «Не беспокоить / Do Not Disturb», операцию `Turn`, состояние `On`, срок `Until Turned Off`.
3. Создать `Dewiar — Не беспокоить — Выкл` с тем же действием, операцией `Turn` и состоянием `Off`.
4. Имена должны совпадать в точности, без дубликатов. В этих командах не должно быть дополнительных действий с файлами, сообщениями или сетью.
5. В Dewiar проверить фразы через «Проверить без выполнения», затем произнести нужную команду. Предварительная проверка только разбирает фразу и разрешения, она не запускает «Команды» и не проверяет фактический режим системы.

Если команды нет, она переименована, утилита не ответила или вернула ошибку, Dewiar сообщает причину и не выдаёт это за успех. После тайм-аута автоматического повтора нет: проверьте режим в Пункте управления. Действие использует разрешение `control_mac_app` в «Руки → Умения», включая требование подтверждения, если оно настроено. Через Shortcuts отдельный Универсальный доступ для этого действия не нужен.

Системная настройка macOS «На всех устройствах / Share across devices» сохраняется: если она включена, система может распространить фокусировку на ваши другие устройства. Dewiar её не меняет. [Включение фокусировки: Apple](https://support.apple.com/en-mt/guide/mac-help/-mchl999b7c1a/mac), [запуск команд из CLI: Apple](https://support.apple.com/en-au/guide/shortcuts-mac/-apd455c82f02/mac).

Названия приложений можно добавлять и удалять. Выбор программы — из установленного списка; разговорные варианты вводятся по одному на строку или через запятую. Для Codex используется `com.openai.codex`: приложение может называться ChatGPT. «Код» не добавлен как сокращение VS Code. В стандартный список включены Claude, Codex, Dewiar, Cursor, Yandex Music, WhatsApp и DeepSeek Harness с согласованными русскими названиями.

Поиск фильтрует действия и приложения, категории позволяют показывать их отдельно, список приложений разбит на страницы по 20 записей. «Проверить без выполнения» использует текущий черновик и показывает действие, цель и необходимость разрешения. Само действие не выполняется. Совпадающие фразы и названия разных программ блокируют сохранение.

Изменения вступают в силу после «Сохранить изменения» без перезапуска. «Вернуть стандартные» меняет черновик и требует сохранения. Данные хранятся в `settings.json → voice_commands`; списки заменяются целиком, поэтому удалённые названия не возвращаются при загрузке. При переходе старых настроек к редакции 2 добавляются только новые действия фокусировки и четыре новые группы приложений, если они не конфликтуют с пользовательскими назначениями. Старые удалённые названия не восстанавливаются; после сохранения редакции 2 удалённые новые назначения также остаются удалёнными.

Разрешения остаются в «Руки → Умения». Управление приложениями macOS учитывает настройку `control_mac_app`, музыка — `yandex_music`. Подтверждение использует существующий механизм вопросов Dewiar. Для сворачивания нужен системный Универсальный доступ. Закрытие не принудительное; Finder и сам Dewiar защищены от завершения этим инструментом.

«Найди песню …», «Открой песню …», «Включи песню …» открывают поиск с исходным названием в установленной Яндекс Музыке через её зарегистрированную схему `yandexmusic://search?text=…`. При отсутствии программы открывается сайт. Первый результат автоматически не выбирается, воспроизведение не обещается. «Открой музыку» открывает само приложение.

Проверки: `tests/voice_commands_test.py`, `tests/mac_control_test.py`, `tests/voice_commands_ui_test.py`. UI проверен в Chromium и WebKit; системные действия в тестах подменены.

## Помощь в разговоре

Лира использует раздел руководства `voice-commands`, который автоматически попадает в контекст вопросов о настройке команд. Она объясняет интерфейс и предлагает помощь, если пользователь затрудняется. Проверенное отсутствие приложения по настроенному или явно указанному названию сопровождается предложением проверить названия.

Инструмент `voice_command_settings` читает текущие данные (`show`) или готовит одно изменение (`propose`): добавить/удалить фразу, добавить/удалить дополнительное название, включить/выключить действие. Предложение проверяется на конфликты и пока ничего не сохраняет. `voice_command_apply` применяет его через обязательное подтверждение пользователя, даже если галочка подтверждения инструмента выключена. Предложение действует 10 минут и отклоняется, если за это время настройки уже изменились. Разрешения инструментов остаются прежними.

## Завершение диктовки в поле сообщения

После нажатия микрофона в окне агента произнесите имя текущего помощника в конце фразы
или отдельно. Например, «Составь список, Лира». Отдельное «Лира» отправит уже накопленный черновик.
Дождитесь паузы и распознавания. Завершающее слово удаляется; слова внутри предложения
и имя другого помощника остаются текстом и не отправляют его. Пустая команда без черновика
и вложений не создаёт пустой запрос. Эти команды действуют только в диктовке через кнопку
микрофона; запись встреч и обычный разговор они не завершают.

Повторное нажатие микрофона прерывает запись и сохраняет уже распознанный текст.
Стрелка вверх дожидается распознавания и отправляет черновик.
Enter в окне агента добавляет новую строку. Подсказка поля показывает имя выбранного помощника.

## Фоновая диктовка и копирование текста

«Лира, слушай» или «Лира, записывай» включает непрерывную диктовку без открытия окна.
Продиктуйте текст и скажите «Лира, текст», «Лира, вставить» или «Лира, добавить».
Текст заменит содержимое буфера обмена и, если фокус находится в поддерживаемом
поле другого приложения, будет вставлен туда без отправки. Иначе его можно вставить
вручную из буфера; черновик останется в диктовке. После команды прослушивание
продолжается. В открытом окне Лиры фоновый черновик можно увидеть и отредактировать.
При диктовке кнопкой микрофона «Лира, текст» копирует текущий текст поля и не
завершает запись.

«Лира, скопировать» копирует весь текст без вставки, независимо от выделения.
Если диктовка в поле сообщения уже остановлена, «Лира, скопировать» и «Лира,
вставить» по-прежнему обрабатывают его черновик при включённом голосовом режиме.

«Лира, отмена» очищает фоновый черновик; «Лира, закончи диктовку» прекращает
прослушивание, когда черновик пуст. Одно имя или «Лира, появиться» показывает окно.
Для вставки в другие приложения на Mac разрешите Dewiar «Универсальный доступ»;
защищённые поля не поддерживаются.
