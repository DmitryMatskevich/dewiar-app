# Приложения, окна и курсор на Mac

В Dewiar.app команды работают в тексте и через существующий голосовой ввод:

- «Открой Калькулятор».
- «Переключись на Safari».
- «Закрой Калькулятор».
- «Перенеси окно Safari на второй экран».
- «Перенеси Safari на левый экран».
- «Перемести курсор мыши на Safari».
- «Покажи мониторы».

Используются установленные `.app` и запущенные приложения текущего пользователя. Имена сопоставляются точно, через русские псевдонимы или единственное совпадение по целым словам. Неоднозначные названия требуют уточнения. Пользовательские строки не вставляются в shell/AppleScript.

`control_mac_app` доступен модели только на Mac с интерфейсом Dewiar. Ядро интерфейса запускается с DEWIAR_MAC_DESKTOP=1, в том числе в текстовом режиме. Самостоятельный сервер без интерфейса инструмент не получает. Существующие настройки включения и подтверждения в «Руки → Умения» действуют и для прямых команд; при обязательном подтверждении команда проходит через обычную обработку моделью.

## Разрешения

Запуск (`open -a`), переключение (`NSRunningApplication`) и обычное завершение (`terminate`) не требуют Универсального доступа. `terminate` может открыть диалог сохранения. Успех закрытия сообщается после проверки `isTerminated`; если приложение ещё работает, сообщается только о запросе завершения. Force quit не применяется, Finder и сам Dewiar этим инструментом не завершаются.

Перемещение окон и курсора требует «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → Dewiar». В «Руки» есть проверка состояния и кнопка открытия этого раздела. Проверка не показывает модалку и не меняет разрешения. Для запуска из исходников выводится предупреждение: системный доступ может относиться к Python/приложению запуска.

Постоянная подпись необходима для устойчивой идентичности приложения после обновлений; подготовка описана в [macos-microphone-signing.md](macos-microphone-signing.md). Системные базы разрешений не изменяются программно.

## Окна и экраны

Инструмент предоставляет действия list, screens, windows, open, focus, quit, move, cursor. Для нескольких окон выбирается сфокусированное; если его нельзя определить, требуется номер window из windows. Название приложения и номер окна не заменяются приблизительным выбором.

Экраны нумеруются с 1: основной, затем остальные по расположению. Координаты Cocoa переводятся в координаты Accessibility/Quartz, учитываются отрицательные координаты, рабочая область с Dock и строкой меню. При переносе сохраняется относительное положение, размер уменьшается при необходимости; результат проверяется чтением фактических координат. Приложение может ограничивать минимальный размер. Полноэкранные и свёрнутые окна требуют сначала обычного оконного режима; переключение Spaces не выполняется. Для зеркальных дисплеев нужен расширенный рабочий стол.

Курсор перемещается к видимой области выбранного окна после активации и AXRaise через CGWarpMouseCursorPosition. Нажатия кнопок мыши не генерируются.

## Проверка

`tests/mac_control_test.py`: разбор команд, точные имена/неоднозначность, фиксированный argv, нормальное завершение с диалогом, защита Finder/Dewiar, отсутствие мутаций без разрешения, отрицательные координаты, уменьшение окна, один/несколько/зеркальные экраны, проверка переноса, курсор без клика, полноэкранные/неоднозначные окна, изоляция экзамена, настройки подтверждения.

Нативный Cocoa/WebKit smoke проверяет блок «Руки» и переходы запрещено/разрешено на синтетическом API. Реальный AX статус и координатные bindings проверены без запроса разрешения. На машине один физический экран; перенос на второй проверен с тестовыми экранами, живой сценарий с двумя мониторами остаётся для приёмки.
