# Strata в Dewiar

В «Модели → Модель на этом компьютере» добавлен отдельный блок Strata. Обнаружена установленная Strata Desktop 0.2.6 (`ai.strata.desktop`), официальный CLI 0.1.51 и пакет `qwen3.8-flash-next-q2_0`. Это Strata из проекта Niko1221/Strata, а не одноимённая MLX-библиотека amperor-strata.

## Через приложение Strata

1. В Strata загрузите нужную модель и оставьте приложение работающим.
2. В Dewiar укажите API, обычно `http://127.0.0.1:8080/v1`. Если в Strata задан ключ API, введите его в соседнем поле. Dewiar не извлекает ключ из файлов другого приложения.
3. Нажмите «Получить список моделей Strata». Список берётся из `/v1/models`; он содержит модели, доступные серверу, а не просто лежащие на диске.
4. Выберите модель и нажмите «Использовать модель». Можно подключить несколько моделей отдельными профилями. При повторном подключении той же модели сохраняются приоритет и расписание.

При включённом автовыборе учитываются приоритет и часы работы профиля: выбор профиля не отключает общий автовыбор. Проверьте таблицу маршрутизации, если следующей остаётся другая модель.

Подключение использует существующий OpenAI-совместимый транспорт Dewiar: потоковый текст, история, ключ и структурированные вызовы инструментов. В запросе явно передаётся `strata_mcp:false`: инструменты выполняет Dewiar, а не второй параллельный агент Strata.

## Без окна Strata

Dewiar ищет официальный CLI в `~/.local/share/strata/terminal/current`, затем — в ресурсах установленного Strata.app. Если отдельный CLI и движок установлены, окно и ресурсы GUI-приложения для этого режима не нужны. Dewiar не встраивает и не скачивает движок или десятки гигабайт весов самостоятельно.

1. Выберите установленный пакет из списка. Список читается из известных профилей `~/.local/share/strata/install/strata-*.json`.
2. Укажите контекст (1024–32768 токенов, по умолчанию 4096).
3. Нажмите «Запустить без окна Strata». После появления статуса готовности нажмите «Использовать движок Dewiar».
4. «Остановить движок Dewiar» останавливает только созданный Dewiar процесс. Чужая Strata, Ollama и LM Studio не закрываются.

Профиль запуска копируется в приватную `state/strata/run.json`; исходный профиль не меняется. Запуск — `strata serve` с официальным компонентом, адресом 127.0.0.1, отдельным случайным ключом и `--offline`. Команды до запуска, MCP, произвольные исполняемые файлы и переменные загрузки сторонних библиотек из исходного профиля не переносятся. Для снижения нагрузки этот режим текстовый, без MTP/зрения. Регистрируется готовность самого движка, не только открытый TCP-порт.

При закрытии Dewiar его движок останавливается; при новом запуске автоматической загрузки весов нет. После повторного запуска подключение обновляется в прежнем профиле по идентификатору пакета, сохраняя приоритет и расписание даже при изменении порта/ключа.

## Формат и память

У Strata нет универсального «формата Strata», заменяющего все модели. У установленной версии используются специальные GGUF-шарды, подготовленный пакет, tokenizer и совместимый движок. Нельзя считать, что произвольный GGUF, MLX или safetensors можно загрузить тем же способом без подготовки. Dewiar использует уже установленный рабочий профиль Strata.

[Официальное описание пакетов](https://github.com/Niko1221/Strata/blob/main/docs/MODELS.md), [запуск на Mac](https://github.com/Niko1221/Strata/blob/main/docs/MAC.md).

Перед своим запуском Dewiar проверяет консервативный бюджет: размер первого native-шарда плюс примерно 8 ГиБ запаса и небольшой запас на контекст. Это ограничитель безопасного старта, не точное измерение всех вариантов mmap/cache. Другие программы не выгружаются автоматически. Подключение к уже работающему API не запускает вторую копию весов.

На проверяемом Mac свободно около 33 ГиБ при оценке около 43 ГиБ для Q2_0; полный запуск весов не выполнялся. Нужно освободить память или использовать уже работающий API Strata. Сам по себе перенос без окна не делает большую модель маленькой.

## Проверки

- `strata_test.py`: каталог без запуска, сохранность исходного профиля, ограничения памяти, запрет произвольного exe/хуков, авторизация API, потоковый текст/вызовы инструментов, собственный процесс и остановка без затрагивания чужого сервера.
- `strata_runtime_test.py` и `--bundle`: настоящий официальный CLI Strata с его штатным mock-engine (без тяжёлых весов), отдельный ключ, готовность, список моделей и потоковый ответ через исходное/готовое ядро Dewiar. Если CLI не установлен, этот дополнительный тест явно пропускается.
- Нативный Cocoa/WebKit smoke: список моделей, отдельные профили, сохранение приоритетов, повторное подключение собственного движка и видимая ошибка нехватки памяти.
