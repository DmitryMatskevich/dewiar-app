# Добавление источников для транскрибации

В «Задачи → Транскрибировать» доступны:

- **Вставить из буфера** — добавляет скопированные ссылки или полные пути, по одному на строку. Уже введённые источники сохраняются, повторы исключаются. Работает и обычная вставка Cmd+V / Ctrl+V в поле.
- **Из браузера → Взять ссылку** — на macOS добавляет адрес активной вкладки переднего окна выбранного запущенного браузера. Поддерживаются Safari, Google Chrome, Яндекс Браузер, Edge, Brave, Chromium и Vivaldi. После запуска браузера нажмите «Обновить».
- **Выбрать файлы…** — добавляет локальные аудио- и видеофайлы.

При первом получении ссылки macOS может запросить разрешение управлять браузером. Если доступ запрещён, разрешите его в «Системные настройки → Конфиденциальность и безопасность → Автоматизация» или вставьте ссылку из буфера. Другие платформы используют вставку из буфера.

Получение ссылки не запускает транскрибацию. Проверьте список и нажмите «Транскрибировать». При открытии диалога содержимое буфера и вкладок не читается.
