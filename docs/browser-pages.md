# Страницы через браузер

Поводом стал ответ Лиры от 30.10.2026 на ссылку lyricstranslate.com: «Страница закрыта — сайт не пускает без браузера».
Сайт закрыт защитой от ботов: обычному HTTP-запросу он отдаёт 403 и страницу-проверку «Just a moment…» на JavaScript.
Настоящий браузер проходит такую проверку сам за несколько секунд. Есть и другие сайты: они отдают пустой HTML, а текст
дорисовывают скриптом.

Теперь `read_webpage` в таких случаях открывает страницу в установленном Chromium-браузере. Так работают ИИ-агенты
с «руками в браузере».

## Как это работает

Каскад в `core/tools.py → t_read_webpage`:

1. **Обычный запрос (httpx).** Нормальные сайты читаются как раньше: браузер не запускается.
2. **Браузер в фоне** (`core/browserpage.py`, headless) — если:
   - ответ 403/429/451/503 или ошибка соединения;
   - ответ 200, но вместо страницы — проверка (`is_challenge`, текста меньше 1500 знаков);
   - страница пустая (`PAGE_EMPTY`) — текст рисует скрипт.

   Браузер ждёт до 25 секунд: страница должна загрузиться, проверка пройти, текст появиться. Затем он забирает HTML
   и видимый текст и закрывается штатно (`Browser.close`), чтобы cookies сохранились в профиле.
3. **Сервер Dewiar** (`dewiar_web`) — прежний запасной путь при 403/451 и сетевых ошибках. Если сервер получил ту же
   страницу-проверку, она не выдаётся за текст.
4. **Нужен человек.** Проверка не проходит сама (капча, вход). Тогда модель получает `BROWSER_NEED_USER`: спросить
   «Открыть страницу в окне браузера?», а после «да» вызвать `read_webpage` с `visible=true`. Окно открывается у
   человека, Dewiar ждёт до 150 секунд и читает страницу. Cookies остаются в профиле, поэтому следующие страницы
   этого сайта читаются в фоне.

Капчи Dewiar не решает: проверку проходит человек. В фоновом режиме подменяется только признак `HeadlessChrome`
в User-Agent и выключается `AutomationControlled`, чтобы браузер выглядел обычным.

## Браузер и профиль

- Поиск исполняемого файла (`find_browser`):
  - `DEWIAR_BROWSER`;
  - на macOS — `/Applications` и `~/Applications`: Google Chrome, Microsoft Edge, Яндекс Браузер, Brave, Chromium,
    Vivaldi;
  - на Windows — Program Files и LOCALAPPDATA;
  - на Linux — `which google-chrome`, `chromium`, `microsoft-edge` и другие.
- Safari и Firefox не подходят: нужен протокол DevTools (CDP).
- Браузер ищется при каждом вызове. Если пользователь установил Chrome, перезапускать Dewiar не нужно.
- Профиль — `STATE_DIR/browser`, отдельный от профиля пользователя. Вкладки, пароли и история человека
  не используются.
- Управление — CDP по WebSocket через уже имеющуюся зависимость `websockets` (sync-клиент, `proxy=None`
  для 127.0.0.1). Новых зависимостей нет: Playwright в сборку не входит.
- Порт — `--remote-debugging-port=0`, номер читается из `DevToolsActivePort` в профиле.
- Один браузер за раз (`_lock`): профиль нельзя открыть двумя процессами.

## Безопасность

- Включён стоп-кран «Ничего не уходит с компьютера» (`egress.local_only()`) — браузер не запускается. Отдельный
  процесс браузера не проходит через сокетный стоп-кран ядра, поэтому проверка делается до запуска.
- Каждое открытие пишется в журнал «Что уходило наружу» как «Страница через браузер Dewiar» (по имени узла).
- `DEWIAR_DRY_TOOLS`, `DEWIAR_EXAM_LAUNCH`, `DEWIAR_NO_BROWSER` — браузер не запускается: тесты и экзамен.
- На сервере (`hooks["server"]`) фоновый режим разрешён, а `visible=true` — нет: окно показать некому.
- Настройка `net.browser_pages` (по умолчанию включена) — студия → «Руки» → «Поиск в интернете» →
  «Страницы через браузер». Само умение «Чтение веб-страниц» по-прежнему выключается в «Руки» → «Умения».

## Проверка

`tests/browser_pages_test.py` запускает локальный сайт. Обычному запросу он отдаёт 403 «Just a moment…», а браузеру —
проверку, которая через секунду показывает текст.

Проверяется:

- обычный сайт читается без браузера;
- стена проходится браузером в фоне;
- текст на скриптах читается;
- неснимаемая проверка даёт `BROWSER_NEED_USER`;
- без браузера, с выключенной настройкой и в тестовом режиме браузер не запускается;
- `visible=true` на сервере — отказ;
- после чтения не остаётся процессов браузера.

Если Chromium не найден, браузерные проверки пропускаются.

Ручная проверка: `python core/browserpage.py https://адрес [--visible]` (профиль во временной папке).
