## Установка на Windows 10 / 11

Два установщика, оба — один файл:

- `Dewiar-Setup-X.Y.Z-online.exe` (меньше 30 МБ) — внутри Python и программа, библиотеки (~100 МБ) скачиваются
  во время установки, нужен интернет, 2–5 минут;
- `Dewiar-Setup-X.Y.Z.exe` (~150 МБ, с сайта `https://dewiar.pro/dwrapp/`, его выкладывает туда `tools/release.sh`) —
  внутри всё, при установке ничего не скачивается.

Запустите любой — права администратора не нужны (программа ставится в ваш профиль:
`%LOCALAPPDATA%\Programs\Dewiar`). Можно выбрать автозапуск вместе с Windows и ярлык на рабочем столе.

- Виджет живёт возле часов: значок Dewiar в области уведомлений. Щелчок — показать виджет,
  правая кнопка — «Студия» и «Выход».
- Окна виджета и студии рисует Microsoft Edge WebView2 — в Windows 11 он есть всегда, в Windows 10 почти
  всегда. Если его нет, установщик предложит скачать; без него ассистент всё равно слушает и отвечает,
  а студия откроется в браузере.
- Где что лежит: настройки — `%APPDATA%\Dewiar`, модели и голоса — `%LOCALAPPDATA%\Dewiar`,
  журналы — `%LOCALAPPDATA%\Dewiar\logs`, заметки и память — «Документы\Dewiar».
- Эхоподавления, как в Linux, в Windows нет: пока ассистент говорит через колонки, он себя не слушает —
  остановить ответ можно нажатием на облик. В наушниках включите «Звук и поведение» → «Я в наушниках» —
  и перебивайте голосом, как в Linux.
- Обновления приходят так же, как в Linux: «Доступна версия…» → нажать — установщик отработает тихо
  и Dewiar перезапустится сам.
- Удалить — «Параметры» → «Приложения» → Dewiar. Заметки в «Документах» останутся.

## Установка на Ubuntu 22.04 / 24.04

```bash
sudo apt install ./dewiar-assistant_X.Y.Z_all.deb
```

Из системы пакету нужны только Python и GTK — они есть в любой Ubuntu с рабочим столом: звук идёт напрямую через
системную libpulse, а Python-библиотеки и ffmpeg скачиваются с PyPI при установке.

Если `apt` всё же пишет «Зависит: … но он не может быть установлен» или «зафиксированы сломанные
пакеты», значит устарел список пакетов системы. Обновите его и повторите установку:
`sudo apt update && sudo apt full-upgrade`.

Нужен интернет: при установке ставятся Python-библиотеки (1–3 минуты) и скачивается модель распознавания
имён (45 МБ, с проверкой контрольной суммы). Если сети не было — модель ассистент докачает сам при первом
запуске, а библиотеки поставит команда `sudo /opt/dewiar/dewiar-env`. Затем откройте
«Dewiar» в меню приложений — появится виджет, а при первом запуске откроется студия.

## Первые пять минут

1. **Мозг.** При первом запуске студия откроется на разделе «Мозг» с вопросом «где будет думать
   ассистент?» — четыре варианта, дальше по шагам:
   - **Сервер компании или дома** — впишите адрес (например, `192.168.1.10`), порт можно не знать:
     программа сама найдёт vLLM, Ollama, llama.cpp или LM Studio и покажет модели.
   - **На этом компьютере** — найдёт запущенные Ollama или LM Studio; если их нет — покажет, как поставить
     Ollama на вашу систему и какую модель взять.
   - **Облако по ключу** — OpenRouter, OpenAI или Claude: вставьте ключ, модель выберется сама
     (с пометкой «рекомендую»), можно сменить.
   - **От администратора** — файл `.dewiar` или адрес сервера Dewiar: настроит всё сразу.
   В конце мастер спросит модель и покажет её ответ — значит, всё работает.
2. **Аккаунт (если есть).** «Подключение» → «Аккаунт Dewiar»: логин и пароль от сайта dewiar.pro —
   ассистент будет отвечать и по вашим Знаниям на сайте. Пароль не сохраняется.
3. **Знакомство.** Лира сама представляется голосом, проверяет микрофон и показывает кнопки виджета. Повторить —
   студия → «О программе» → «Познакомиться заново».
4. **Скажите «Лира, привет».** В фоне один раз скачивается GigaAM (~250 МБ) и голос Piper (~60 МБ), прогресс виден
   под виджетом. Плохо откликается — студия → «Слух» → «Научить имени»: скажите имя три раза, и ассистент будет
   узнавать его мгновенно, даже без интернета. Там же «Что я слышу»: каждая фраза и нашлось ли в ней имя.
5. **Попробуйте:** «Лира, расскажи что-нибудь» — и посреди ответа «Стоп. Короче, одной фразой». «Позови Патрика» —
   слово перейдёт к нему. «Стоп», «хватит», «пауза» — ассистент замолкает и ждёт своего имени. Нажатие на облик —
   говорить без имени, клавиатура в панели виджета — написать вопрос текстом.

Виджет — матово-чёрная карточка (тень рисует сама система): облик персонажа, его имя, ответ текстом и панель внизу
(микрофон, ввод текстом, переключатель персонажей, студия; справа вверху — «спрятать»). Перетаскивается за
любое свободное место, нажатие на облик — говорить без имени. Пока идёт ответ, облик уменьшается и
уступает место тексту.

**Значок.** Кнопка со стрелками внизу карточки сворачивает виджет в маленький круг — он почти не
занимает экран, ассистент продолжает слушать и отвечать голосом. Развернуть — кнопка у края круга
(появляется при наведении). Если нужно подтвердить действие («Да/Нет»), карточка раскроется сама.

**Позвать другого персонажа.** «Лира, позови Патрика» — Лира передаст слово, облик и голос сменятся, и Патрик
продолжит разговор сам. Кодер, Джарвис, Эва и другие — студия → «Персонажи» → «Готовые персонажи», одной кнопкой.

## Телефон и планшет (Android)

Приложение Dewiar для Android — тот же облик и та же команда персонажей, разговор голосом и текстом.
Последняя версия всегда лежит по постоянной ссылке `https://dewiar.pro/dwrapp/Dewiar.apk`; на компьютере удобнее
так: студия → «Подключение» → «Dewiar на телефоне» — QR-код для установки и QR-код, который переносит на телефон
мозг, слух, голос и умный дом этого компьютера.

- **Вход аккаунтом dewiar.pro** — и мозг подключён сразу. Своя модель (например, домашний сервер) не отвечает —
  телефон думает моделями Dewiar и говорит об этом.
- **Напоминания, будильники и таймеры** звонят и на заблокированном экране, переживают перезагрузку и приходят от
  лица персонажа — с его лицом и именем, в том числе на часах.
- **Звонки, SMS, приложения, сайты, погода, фонарик, громкость, заметки, деньги, умный дом Яндекса.**
- **Руки в других приложениях.** Настройки → «Ещё» → «Управлять приложениями» → в «Специальных возможностях»
  Android включить Dewiar. Дальше — «напиши маме в Telegram, что я задержусь», «найди в YouTube…»: ассистент
  открывает приложение, читает экран, нажимает, вводит и листает. Перед отправкой, оплатой и удалением
  спрашивает, пароли не читает и не вводит. На Android 13 и новее для приложения не из магазина сначала нужно
  «Разрешить ограниченные настройки» (подсказка — в той же карточке).
- **Программы на экране.** «Сделай калькулятор», «сделай игру» — программа открывается сразу и остаётся в
  «Мой день» → «Сделанное».
- **Большие задачи** («возьми задачу: сделай презентацию о…») — делает компьютер, а если он выключен — облако Dewiar.
  Когда готово — уведомление и карточка в разговоре: итог и файлы, «Открыть» и «В «Загрузки»». Ход — «Душа» → «Задачи».
- **Голосом или текстом.** Значок динамика вверху — ответы только на экране (в транспорте, на встрече); ещё касание —
  снова голосом. Скорость речи — «Слух и голос», до 2×.
- **Без сервисов Google** (Huawei и др.): распознавание и голос — через сервер Dewiar. Нет русского голоса в
  устройстве — говорит голос Dewiar, у каждого персонажа свой.

## Telegram и MAX

Пишите ассистенту из Telegram — текстом, голосовыми, фото и документами; туда же приходят итоги задач,
напоминания и вопросы «выполнить?» с кнопками. На компьютере: студия → «Подключение» → «Подключить Telegram»;
на телефоне: Настройки → «Ещё» → «Подключить Telegram». Откроется бот Dewiar — нажмите «Запустить», и он ваш.
Компьютер выключен — отвечает телефон или ваш сервер. Так же подключается MAX.

## Синхронизация устройств

Вошли одним аккаунтом dewiar.pro (или одним ключом Dewiar) на компьютере и телефоне — напоминания, заметки,
деньги, «Обо мне», душа и конституция персонажей, дневник и ход задач одинаковые везде; обмен — раз в минуту и сразу
после изменений (студия → «Dewiar.pro» → «Синхронизация»). Obsidian: студия → «Подключение» → Obsidian → «Всё
хранилище — одинаковое на всех компьютерах»; правки в двух местах не теряются — вторая ложится рядом копией
«(конфликт…)», удалённое уходит в корзину Obsidian.

## Разговор: как перебить и остановить

- **Просто начните говорить.** Ответ сразу становится тише («слышу вас»), через секунду речи ассистент
  замолкает, а сказанное принимает как новый вопрос — имя называть не нужно. Кашлянули или сказали «угу» —
  громкость вернётся, ответ продолжится.
- **Стоп-слова:** «стоп», «хватит», «пауза», «тихо», «замолчи», «помолчи», «достаточно», «прекрати»,
  «остановись», «перестань», «отмена», «тишина». Одно слово — просто замолчит и будет слушать.
  «Стоп, расскажи лучше…» — замолчит и ответит на новое.
- Позвать другого по имени, как раньше, тоже можно.
- Настройка — «Звук и поведение» → «Как перебивать». Работает, когда включено эхоподавление.

## Окно и выход: «спрячься», «покажись», «отключись»

- **«Спрячься»** (или «уйди в трей», «убери виджет») — то же, что кнопка «В трей»: виджет исчезает, ассистент
  слушает. Позовёте по имени, придёт напоминание или вопрос «Да/Нет» — появится сам, а после разговора спрячется.
- **«Покажись»** (или «покажи виджет») — вернуть виджет на экран насовсем. Значок Dewiar возле часов → «Показать
  Dewiar» — то же самое.
- **«Отключись»** (или «закрой программу») — выйти из Dewiar совсем: ассистент скажет, как включить снова, и
  завершится целиком — и окно, и ядро (слух, голос). Голосом его после этого не позвать: запустите «Dewiar» из меню
  приложений. При следующем входе в систему он запустится сам, как обычно.
- Значок в трее (Ubuntu): «Показать Dewiar», «Убрать в трей», «Студия», «Выйти из Dewiar». В Windows — «Показать»,
  «Студия», «Выход». «Выйти» завершает всё: в фоне ничего не остаётся.
- Окно пропало (например, интерфейс упал), а ассистент продолжает слушать — назовите его по имени, виджет откроется сам.

## Руки: что ассистент умеет делать

Просто просите словами — модель сама решит, какое умение вызвать:

- «Лира, открой ютуб» / «открой сайт хабра» — откроет в браузере;
- «найди, какая погода завтра в Казани» — поищет в интернете и перескажет, может прочитать страницу;
- «запусти телеграм», «открой калькулятор», «открой загрузки» — программы из меню и папки;
- «включи что-нибудь спокойное», «пауза», «следующий трек», «сделай погромче» — музыка и звук;
- «напомни через 20 минут выключить духовку», «какие у меня напоминания» — скажет вслух в нужный момент;
- «как там батарея и память» — состояние компьютера;
- «выполни команду …» — терминал. По умолчанию выключено; если включить в студии, ассистент
  всегда сначала спросит «Выполнить?», ответить можно голосом («да» / «нет») или кнопкой в виджете.

Студия → «Руки»: любое умение можно выключить или поставить на подтверждение.

Настраивать сервер для этого не нужно. Модель отвечает текстом «вызови такую-то функцию»,
а выполняет её сам Dewiar у вас на компьютере. Если сервер не умеет принимать функции отдельным
полем (например, vLLM без флагов), Dewiar описывает их прямо в запросе и сам находит вызовы в ответе.

## Глаза

Для этого нужна модель со зрением (Qwen-VL, Qwen3.5 и новее, Claude, GPT-4o…):

- «Лира, что у меня на экране?», «посмотри на эту ошибку», «что тут за график?» — снимок экрана.
  На Ubuntu (Wayland) снимок делает системный портал: GNOME спросит разрешение — это нормально.
- «посмотри в камеру, что у меня в руке» — кадр с камеры; каждый раз спрашивает подтверждение
  (можно отключить в «Руках»). ffmpeg для камеры ставится вместе с Dewiar.
- Картинку можно перетащить прямо на сферу виджета или вставить Ctrl+V в поле вопроса.

## Папка ассистента

Всё, что ассистент делает для вас, лежит обычными файлами в папке **~/Dewiar** (путь можно сменить).
Смотреть удобно в студии — раздел «Папка»: дерево слева, красиво оформленная заметка справа, кнопки
«Открыть в файлах» и «Открыть в приложении». В виджете — кнопка с папкой.

- **Заметки** — «Лира, запиши…», «составь список покупок», «запиши план на неделю».
- **Лаборатория** — если задачу проще решить кодом (посчитать, обработать файл), ассистент пишет скрипт
  сюда и запускает его (с вашего разрешения). Рядом — `.log` с выводом: видно, чем он был занят.
- **Дневник** — после содержательных разговоров ассистент коротко записывает, что обсуждали, что вам
  важно и что он может делать лучше.
- **Память / Обо мне.md** — что он о вас знает («запомни, что я не пью кофе»). Читает это перед каждым
  ответом. Файл ваш — лишнее просто сотрите.
- **Напоминания.md** — активные напоминания, обновляется сам.

## Обо мне и мои документы

Студия → «Душа» → «Обо мне»:

- **Что ассистент помнит** — всё, что он узнал о вас («запомни, что я не ем мясо»). Он читает это перед
  каждым ответом. Можно править и стирать прямо здесь.
- **Мои документы — «Знания»** — положите PDF, Word, ODT, текст, Markdown, HTML или CSV (кнопкой или прямо
  в папку «Знания» внутри папки ассистента) и спрашивайте: «что в моих документах про отпуск?». Ассистент
  найдёт нужные отрывки и ответит со ссылкой на файл. Работает без интернета и без сервера; поиск
  понимает формы слов («отпуск», «отпуска», «отпуском»).
- Если вы вошли в **аккаунт Dewiar**, ассистент может спрашивать и ваши Знания на сайте — там поиск
  умнее (векторная база). Какие спросить — решает сам по вопросу.

## Большие задачи в фоне

Для работы, которая занимает минуты или часы, скажите: «Лира, возьми задачу: разберись, почему падают тесты
в проекте ~/code/shop, и почини», «подготовь отчёт о домашних ИИ-серверах». Ассистент заведёт задачу и будет
работать в фоне, а разговаривать с ним в это время можно как обычно.

- **План и журнал.** Задача сама составляет план, отмечает сделанное и ведёт журнал каждого шага. Всё видно
  в студии → «Задачи» (вкладки «План», «Журнал», «Изменения», «Итог») и в папке ~/Dewiar/Задачи.
- **Вопросы.** Если задаче что-то неясно, ассистент спросит вслух. Ответить можно голосом, без имени, в течение
  пары минут после вопроса, или текстом в студии.
- **Готово.** Когда задача закончена, ассистент скажет об этом голосом и покажет итог. Спросите «как там задача?» —
  он расскажет, на каком она шаге. «Останови задачу» и «продолжи задачу» тоже работают.
- **Модель для задач.** Для долгих задач можно выбрать отдельную, более сильную модель: «Задачи» → «Модель для задач».
- **Части одновременно.** Большую работу из независимых кусков — сведения по пяти компаниям, несколько
  разделов отчёта — задача раздаёт помощникам: они работают одновременно (по три), каждый в своей папке; итоги и
  файлы собираются в `parts/` главной задачи. Главная задача сообщает об окончании одна.
- **Часы работы.** Задача идёт кругами по 80 шагов с минутной передышкой — по умолчанию до 15 кругов
  (1200 шагов), «Задачи» → «Настройки задач». Если два круга подряд ничего не продвинулось (план, блокнот и файлы
  не менялись), задача сама встанет на паузу и скажет почему.

### Задачи с телефона, когда компьютер выключен

Поставьте Dewiar на сервер — `sudo dewiar-server setup`, и он будет брать задачи с телефона круглосуточно.
Подробно — в [self-hosting.md](self-hosting.md#ассистент-круглосуточно-dewiar-server).

## Режим кода — как Cursor или Codex

Если у задачи указана папка проекта, ассистент работает с кодом. Он ищет по проекту, читает файлы, правит их
точечно и запускает тесты. **Ваши файлы при этом не трогаются.** Работа идёт в отдельной рабочей копии: для
git-проекта это `git worktree`, в которую переносятся и ваши незакоммиченные изменения, для остальных проектов —
обычная копия.

Когда задача готова: студия → «Задачи» → вкладка «Изменения». Там полный diff. Кнопка «Принять» переносит правки
в ваш проект, «Отклонить» их выбрасывает. Каждую команду в проекте (тесты, сборка) ассистент сначала показывает
вам и спрашивает разрешения. Запускать без вопросов — галочка в «Задачах»; включайте только для своих проектов.

## Готовые навыки

Включены сразу, отдельно ставить ничего не нужно:

- **Программист** (coder) — порядок работы с кодом: понять, найти, поправить, проверить;
- **Ревью кода** (code-review) — найдёт ошибки и риски в изменениях;
- **Разбор ошибки** (explain-error) — объяснит трассировку и предложит исправление;
- **Тесты** (write-tests) — напишет тесты под ваш фреймворк;
- **Git** (git-helper) — ветки, конфликты, «как откатить»;
- **Исследование с отчётом** (research-report), **Письма** (letters), **План дня** (day-planner).

Каждый навык можно посмотреть и поменять в студии: «Навыки и MCP».

## Навыки и MCP

**Навыки** — папки с файлом SKILL.md: сверху имя и описание, дальше инструкции. Формат тот же, что у
Claude и ZCode, поэтому готовые навыки оттуда подходят. Ассистент видит только список навыков и
загружает инструкции, когда просьба подходит. Встроены два: «справка о Dewiar» (спросите
«Лира, как подключить модель?») и «утренняя сводка» («Лира, что у меня сегодня?»).
Установить: студия → «Навыки и MCP» → из файла (.zip или SKILL.md), по ссылке или положить папку
в `~/.config/dewiar/skills/`.

**Создать свой навык** — студия → «Навыки и MCP» → «Создать навык». Опишите словами, что он должен
делать, нажмите «Составить» — Лира напишет черновик, вы поправите и сохраните. Или голосом:
«Лира, научись: когда я говорю „режим фокуса“ — выключи звук и поставь таймер на 25 минут»
(ассистент спросит подтверждение). Любой навык можно «Изменить» и «Скачать» .zip-архивом;
правка встроенного сохраняется вашей копией.

**Каталог с сайта** — адрес JSON-файла со списком навыков (пример — `server/skills-catalog.example.json`)
вводится в студии или приходит из описания сервера полем `"catalog"`. Пользователь видит список и
ставит навыки одной кнопкой.

**MCP** — стандарт подключения внешних инструментов: файлы, заметки, календари, базы, ваши
сервисы. В студии есть кнопки для популярных официальных серверов (нужен Node.js или uv) и форма
для своего — программой на компьютере или по адресу. Инструменты, которые сервер не пометил как
«только чтение», спрашивают разрешение; серверу, которому доверяете, это можно отключить.

## Голоса

По умолчанию — **Vosk TTS** — русские нейросетевые голоса от создателей Vosk: чистое произношение и
ударения. Модель скачивается один раз (пока качается — говорит Piper). Если в журнале «Vosk TTS не загрузился:
No module named 'vosk_tts'» — библиотека не поставилась при установке, помогает `sudo /opt/dewiar/dewiar-env`. Мужские и женские голоса ассистент
определяет сам и раздаёт персонажам по полу; поменять — в карточке персонажа («Голос Vosk TTS»). У Джарвиса
оставлен голос Piper (Руслан) — он и так хорош. Послушать все голоса — студия → «Голос».

## Обработка голоса

Студия → «Голос» → «Обработка голоса»: «Чище», «Теплее», «Глубже», «Кино», «ИИ из фильма», «Космос».
Голос становится ниже без замедления речи, добавляется тембр и пространство (реверберация). Работает с
любым синтезатором. У каждого персонажа своя обработка по умолчанию (например, у Джарвиса —
«Кино»); поменять — в карточке персонажа. Нажатие на вариант сразу даёт его послушать.

## Телевизор

«Лира, включи на телевизоре клип …», «покажи на телевизоре сайт …», «пауза на телевизоре», «сделай
телевизор потише». Работает с Chromecast, Google TV, Android TV и телевизорами со встроенным Chromecast в той
же сети Wi-Fi. Нажать кнопку «Трансляция» в браузере ассистент пока не может — он отправляет видео на
телевизор напрямую по сети.

## Свой персонаж

Студия → «Персонажи» → «Создать своего»: имя, слово для вызова, характер, голос, цвет и облик.
Облик — одна из семи анимаций (включая живой знак Dewiar) или ваше фото, которое станет голограммой. Подойдёт любое слово
для вызова. Встроенных персонажей тоже можно
изменить; «Сбросить к заводскому» вернёт их как было.

## Как ассистент слышит имя

Работают два уровня. Маленькая офлайн-модель Vosk мгновенно ловит имена из своего словаря —
Лира, Патрик, Агент, Джарвис, Эва. Имён, которых в словаре нет (например, придуманных вами), она не знает, поэтому
каждую короткую фразу дополнительно проверяет точная модель GigaAM: имя должно стоять первым словом (или после
«эй», «слушай», «привет»). Так работает любое имя, в том числе придуманное вами. Проверяются
только первые 3 секунды фраз и только когда кто-то говорит. Выключить: «Звук и поведение» →
«Узнавать любые имена».

## Как произносится «Девиар»

В тексте — «Девиар» и «Dewiar», в голосе — «ДэвиАр» с ударением на последний слог. Это правило
произношения встроено: локальные голоса получают написание, которое синтезатор читает правильно.

## Близкие: переписка и звонки между помощниками

«Лира, напиши маме, что я задержусь» — у мамы её помощница покажет сообщение и прочитает вслух. Можно отправлять файлы
(до 10 МБ) и звонить — с голосом и видео; всё шифруется на устройствах.

- Пригласить: студия → «Близкие» → «Пригласить близкого» (на телефоне — сердечко вверху → «Пригласить»): печать Dewiar
  (её читает сканер Dewiar и Google Lens; «Обычный QR» — для других камер) и ссылка на 7 дней.
- Принять: открыть ссылку или отсканировать печать на телефоне («Сканировать приглашение» или «отсканируй код»);
  на компьютере — вставить ссылку в «Пришла ссылка-приглашение?».
- Голосом: «напиши маме…», «что мне писали?», «позвони маме», «сделай видеозвонок маме».
- Файлы от близких на компьютере — в папке ассистента «Близкие/<имя>»; отправка файлов голосом — с подтверждением.

## Сканер кодов (телефон)

«Отсканируй код», «проверь честный знак» — камера читает QR, Aztec, печать Dewiar, штрихкоды (EAN, UPC, Code 128…) и
Data Matrix. Ссылку предложит открыть или скопировать; по коду товара Лира сама найдёт, что это; подлинность упаковки
«Честного знака» показывает его официальное приложение.

## Напоминания на часах

Напоминание с телефона приходит и на умные часы (Honor/Huawei, Wear OS и другие, которые показывают уведомления
телефона) — с кнопками «Понял» и «Через 10 минут». Не видно на часах — в приложении часов включите уведомления для Dewiar.

## Ваши данные и приглашения друзей

- «Ваши данные» — студия → «Безопасность», телефон — «Ещё» → «Ваши данные»: что хранится у вас, куда уходит вопрос
  модели, что шифруется. Лира ответит на «как защищены мои данные?» по тому же тексту.
- «Рефералы» — студия → «Рефералы», телефон — «Близкие» → «Рефералы»: созвездие приглашённых, код и ссылка; другу —
  подарок талерами сразу, вам — когда он попользуется Dewiar несколько дней. Приглашённым можно писать и звонить:
  «Позвать в Близкие» — друг соглашается сам.

## Если что-то не так

Сначала: студия → «О программе» → **«Сохранить отчёт»** сразу после проблемы. На рабочем столе появится
файл с журналом и настройками (без ключей и паролей) — пришлите его, по нему видно, что случилось.


| Симптом | Что делать |
|---|---|
| Не откликается на имя | Студия → «Слух» → «Научить имени»; ниже, в «Что я слышу», видно каждую фразу и нашлось ли имя |
| `apt`: «Зависит: … не может быть установлен» | Устарел список пакетов системы: `sudo apt update && sudo apt full-upgrade`, затем снова `sudo apt install ./dewiar-…deb` |
| «Не удалось поставить библиотеки Python» при установке | Не было интернета. Когда появится: `sudo /opt/dewiar/dewiar-env` |
| `apt`: «неподдерживаемый файл» | Файл по этому пути не целый `.deb` (не докачался, переименован). Проверьте: `dpkg-deb -I файл.deb` должен показать описание пакета |
| «Не получилось: …» вместо ответа | Студия → «Мозг» → «Проверить»: покажет модель, API и настоящий ответ. Размышляющие модели (Qwen) ассистент теперь сам переспрашивает без размышлений |
| Не реагирует на имя | Студия → «Звук и поведение»: выбран ли нужный микрофон. Лог: `journalctl --user -u dewiar-core -f` |
| «Не могу подключиться к …» | Адрес модели должен оканчиваться на `/v1`; сервер vLLM запущен с `--host 0.0.0.0` |
| Виджет прямоугольный, без скруглений | Сеанс без X11/Xwayland (редко). Ассистент при этом работает |
| Слышит сам себя | «О программе» → «Эхоподавление». Если выключено — перезапустите: `systemctl --user restart dewiar-core` |
| Окно студии белое | `WEBKIT_DISABLE_DMABUF_RENDERER=1` уже включён; обновите драйвер видеокарты |

Удаление: `sudo apt remove dewiar-assistant`. Настройки и персонажи остаются в
`~/.config/dewiar`, модели — в `~/.local/share/dewiar` (можно удалить вручную).
