# Dewiar на своём сервере и сайте

Для владельца сайта и администратора: как выпускать обновления, раздавать модели и готовые настройки, поднять
сервер речи и держать Dewiar включённым круглосуточно. Сайт dewiar.pro (облако, вход, боты Telegram и MAX) в эту
копию не входит.

## Выпуск версии одной командой

```bash
tools/release.sh /путь/к/сайту/dwrapp            # .deb и установщики Windows — сразу в папку обновлений
tools/release.sh /путь/к/сайту/dwrapp --docker   # то же в контейнере, в систему ничего не ставится
android/tools/build_apk.sh                       # приложение Android (без Gradle)
```

Клиенты видят новую версию сами («Доступна версия…»), текст «Что нового» берётся из `RELEASE_NOTES.md`.

## Ассистент круглосуточно: `dewiar-server`

Тот же пакет на сервере (Ubuntu/Debian, без экрана и звука) берёт большие задачи с телефона, отвечает в Telegram,
ведёт напоминания и календари, даже когда домашний компьютер выключен. Для телефона это ещё один компьютер в
вашем аккаунте.

```bash
sudo apt install ./dewiar-assistant_X.Y.Z_all.deb
sudo dewiar-server setup      # логин dewiar.pro, адрес и имя модели (пусто — модели Dewiar по аккаунту)
sudo dewiar-server status     # log — журнал, restart | stop | remove
```

Служба `dewiar-server.service` работает от пользователя `dewiar-assistant`, данные — в `/var/lib/dewiar-assistant`.
Пароль никуда не записывается — только токен входа. Есть Ollama или vLLM рядом — укажите его адрес
(`http://127.0.0.1:11434/v1`), и задачи будут думать своей моделью.

## Обновления и модели со своего сайта

Раз в 6 часов (и через минуту после запуска) ассистент проверяет адрес `https://dewiar.pro/dwrapp/latest.json`.
Если там новая версия, он скачивает пакет, сверяет контрольную сумму и показывает кнопку «Установить» в виджете и в
студии («О программе»). GNOME спросит пароль, и ассистент перезапустится уже новым. Терминал не нужен.

С того же сайта скачиваются и все модели: распознавание имён, GigaAM, голоса Vosk TTS и Piper. Так
быстрее, и пользователи не зависят от alphacephei.com и huggingface.co. Каждый файл проверяется по sha256. Если модели
на сайте нет или сайт недоступен, ассистент берёт её с исходного места, как раньше.

**Как выложить на сервер.** Первый раз выполните команду, она скачает на сервер все модели (≈0,7 ГБ) и положит пакет:

```bash
python3 tools/publish_update.py dewiar-assistant_X.Y.Z_all.deb /var/www/dewiar.pro/dwrapp --models
```

Для каждой следующей версии достаточно так:

```bash
python3 tools/publish_update.py dewiar-assistant_X.Y.Z_all.deb /var/www/dewiar.pro/dwrapp --notes "Что нового"
```

Путь к папке укажите свой. Главное — чтобы сайт отдавал её как `https://dewiar.pro/dwrapp/`. Нужен только Python 3,
установка библиотек не требуется. В папке появятся `latest.json`, пакеты (старые остаются, на них можно откатиться) и `models/`.

Папка публичная, поэтому в ней только пакеты и модели. `.env`, базы данных и всё служебное держите вне её. Для nginx
полезно запретить скрытые файлы:

```nginx
location /dwrapp/ { alias /var/www/dewiar.pro/dwrapp/; location ~ /\. { deny all; } }
```

Другой адрес можно указать в студии: «О программе» → «Адрес обновлений».

## Готовые настройки для пользователей

Три способа, от простого к «ноль кликов»:

1. **Файл.** Настройте Dewiar у себя → «Подключение» → «Экспортировать» (ключи по умолчанию не
   попадают в файл). Отправьте файл `.dewiar` — у пользователя он откроется двойным щелчком.
2. **Адрес сервера.** `server/install-server.sh` сам создаёт `/etc/dewiar-server/dewiar.json`
   и отдаёт его по адресу `http://сервер:8090/.well-known/dewiar.json`. Пользователь вводит
   `сервер:8090` и код доступа — всё. Если перенесёте файл на свой домен
   (`https://dewiar.ru/.well-known/dewiar.json`), достаточно ввести `dewiar.ru`.
   Кнопка для сайта: `<a href="dewiar://connect?server=dewiar.ru">Подключить Dewiar</a>`.
   Клиенты при каждом запуске тихо обновляют с этого адреса модель, распознавание, голос и навыки.
   Программы MCP и разрешения так не меняются — для них нужно согласие пользователя.
3. **Свой пакет.** Положите свой `provision.json` (пример — `server/dewiar.example.json`) и соберите:
   `PROVISION=provision.json tools/build_deb.sh dist`. У всех, кто поставит такой пакет, всё
   настроено с первого запуска.

В описании можно попросить код доступа: `"key": {"required": true, "hint": "…"}`, а в адресах
и ключах написать `${KEY}` — туда подставится код, который введёт пользователь.

## Сервер речи и моделей: Dewiar Server

Папка `server/` ставится на машину с GPU (там же, где vLLM):

```bash
sudo ./install-server.sh              # распознавание GigaAM на GPU, порт 8090
sudo ./install-server.sh --with-tts   # плюс голоса Qwen3-TTS (vLLM-Omni), порт 8091
```

В конце скрипт напечатает адреса и ключ — вставьте их в студии: «Слух» → «Сервер
распознавания» и «Голос» → «Сервер синтеза». Проверить голос на сервере:
`server/tts/check-tts.sh`. Если сервер недоступен, компьютер сам вернётся к локальным моделям.
