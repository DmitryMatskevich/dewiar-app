# Проверки по демонстрационному ролику

Источник: https://www.youtube.com/watch?v=lXRiHj9j9Pk. Разобраны авторские русские субтитры всех 30 глав; полный текст не включён в репозиторий.

Реестр требований и пробелов: `data/macos-video-acceptance.json`. В нём отдельно указаны телефонные возможности, внешние продукты автора и сценарии, которым нужны реальные устройства, модели или сервисы.

## Воспроизводимый локальный прогон

```sh
.venv/bin/python tools/run_video_checks.py --native --bundle
```

Предварительно собрать `.app`:

```sh
.venv/bin/pyinstaller --noconfirm packaging/macos.spec
```

Прогон выполняет 53 набора в отдельных конфигурациях и хранилищах, затем открывает настоящие окна Cocoa из исходников и `.app`. Старые тесты с ❌ при нулевом коде выхода считаются провалом. При таймауте завершается группа процессов конкретного теста.

Проверяются открытие и повторное открытие быстрой идеи и блокнота, сохранение идеи через интерфейс, загрузка суфлёра, отображение пропущенного повторяющегося напоминания и изменение масштаба в обе стороны. Микрофон, личный буфер обмена и основной аккаунт при этом не используются.

Результаты и журналы: `work/video-checks`. `acceptance-report.md` — таблица по главам, `acceptance-results.json` — машинные результаты. `--report-only` оформляет ранее сохранённые результаты и не запускает проверки заново.

## Настоящая локальная модель

```sh
.venv/bin/python tools/probe_macos_live.py
```

Для установленной Qwen с рассуждениями и отдельным отчётом:

```sh
.venv/bin/python tools/probe_macos_live.py --model qwen3.6:35b --thinking on --max-tokens 4096 --output work/model-switch/qwen3.6-live.json
```

Отдельная необязательная проверка требует уже установленную `gemma4:12b` в Ollama на `127.0.0.1:11434`. Ничего не скачивает. Проверяет память после нового разговора, чтение синтетического чека и создание напоминания по синтетическому стикеру. Ответы поступают от настоящей модели через ядро; локальный шлюз лишь ограничивает контекст до 8192. Данные временные, команды и произвольный код модели запрещены, внешние интеграции выключены. Кроме пяти предметных инструментов доступны два встроенных инструмента чтения навыков.

Результат: `work/video-checks/live-local-model.json`. Это три конкретных проверки, а не полный экзамен способностей и не гарантия качества всех моделей.

## Границы приёмки

Успех локального теста на запрограммированном сервере подтверждает протокол и состояние приложения. Он не подтверждает реальный звонок, распознавание речи, OCR, качество рассуждений, доставку почты или работу чужого сервера. Настоящая модель проверяется отдельным прогоном.

Для полной приёмки остаются голос и аудиозахват Mac, глобальные клавиши, работа после сна без окна, камера и сканер, два устройства, внешние интеграции, подписки моделей, постоянная подпись и полный экзамен на выбранных моделях. Эти пункты не помечаются пройденными по наличию исходного кода или успешной заглушке.
