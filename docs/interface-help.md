# Контекстная справка интерфейса

В каждом из 33 разделов настроек есть одна кнопка «Помощь» у заголовка. Ещё одна статья посвящена слепку знаний и открывается из его меню. Всего 34 локальные статьи.

Отдельные кнопки «?» рядом с полями не добавляются. Пояснения находятся в title существующих кнопок, полей, переключателей, списков и сводок лимитов. Пояснения добавляются также к динамически созданным профилям, команде задачи и результатам поиска. В главном окне расширены пояснения 29 кнопок с сохранением динамического состояния микрофона и модели.

## Панель

- Для чего раздел, шаги настройки, примеры, важные ограничения, устранение неполадок.
- Поиск по всем локальным статьям, список тем, возврат к текущему разделу.
- Чтение не вызывает модель, не отправляет примеры, не изменяет формы и не открывает внешние сайты.
- Escape и крестик закрывают панель с возвратом фокуса. В узком окне панель полноширинная, с циклическим Tab; на широком экране остальной интерфейс остаётся доступным.
- Светлые и тёмные темы, системное уменьшение анимации.

Статьи поиска не содержат пользовательские чаты, секреты или значения полей. При подготовке title значения input/textarea не читаются. HTML статей экранируется; поисковая строка не вставляется в HTML.

## Источники

- `ui/assets/help.js`: исходные статьи.
- `ui/assets/help-current.js`: актуализация Mac, новые разделы, ограничения прототипа. Здесь описаны подписки, Strata, разрешения Mac, приоритеты, архив чатов, ежегодные дни рождения, совет моделей и резервная отправка отчётов.
- `ui/studio/context-help.js`: панель, поиск, фокус, title. Для известных действий/полей используются явные описания; для остальных — существующее описание, подпись, встроенная поясняющая строка и контекст раздела.
- `ui/studio/context-help.css`: геометрия и тема панели, без изменения остального интерфейса.
- `ui/assets/hud-help-titles.js`: пояснения кнопок главного окна; существующий обработчик всплывающих подсказок HUD сохранён.

Для новой настройки сначала добавьте содержательное описание в реестр поля/id/действия. Для нового раздела добавьте статью по ключу `p-<ключ>`. Не описывайте запланированную возможность как уже работающую. Числа баланса и лимитов не следует придумывать.

## Проверка

`tests/context_help_test.py` открывает настоящую страницу настроек в Chromium без внешних служб. Проверяет все статьи, открытие/закрытие, поиск и отсутствие результатов, экранирование, отсутствие исполняемых примеров, отсутствие вызовов ядра, сохранение несохранённых полей, возврат фокуса, клавиатуру узкой панели, новые карточки и все title. В фикстуре покрыты 396 кнопок настроек и 29 кнопок HUD; число динамических кнопок в пользовательской сессии может отличаться. Проверяются темы neusky/neudark/brand и ширины 1440/1024/390.

`tests/snapshot_ui1025_test.py` проверяет совместимость справки слепка. В нативную Cocoa/WebKit проверку `tools/subscription_ui_smoke.js` включены все локальные статьи, поиск, закрытие, title и отсутствие лишних «?»/команд. Отчёт содержит `context_help:true` и `help_articles:34`.


## Материалы демонстрационного видео

Ранее сохранённые субтитры YouTube lXRiHj9j9Pk используются через адаптированные сценарии и ограничения, без включения полного транскрипта в приложение. Связь всех 30 глав со справкой и происхождение текста — `data/help-video-reference.json`; локальный каталог — `ui/assets/help-video-reference.js`; инструкции — `ui/assets/help-video-notes.js`. Внизу связанной статьи можно раскрыть «По демонстрации автора»: время, тему и поправку для Mac. Само раскрытие не загружает видео.

Ссылка с t=2005s — 33:25, внутри главы V15 (30:50–35:50) о памяти, душе, конституции и дневнике. Чётко разделены текстовая память и обучение модели, ночной дневник и еженедельное обновление души, принципы и технические ограничения. Для пользовательских сценариев добавлены длительные задачи, работа по документу, локальное видео/субтитры, цепочка конспект/презентация, фото чека и стикера, условные напоминания, Obsidian/интеграции и быстрая идея.

Проверка каталога без изменения файлов: `.venv/bin/python tools/sync_help_video_reference.py --check`. После правки JSON запустите ту же команду без `--check`. Полный сохранённый разбор находится в `../plan/video-help-source-notes.md`; транскрипт — локально в `work/video-reference/transcript.txt`. Прежние результаты функциональной приёмки видео не объявляются заново пройденными после правки справки.


Нативная адресная книга и создание в двух приложениях описаны в [macos-contacts.md](macos-contacts.md); раздел «Контакты» добавлен к локальной справке.
