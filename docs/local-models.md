# Общий список локальных моделей

В «Модели → На этом компьютере» основной список объединяет Ollama, LM Studio и Strata. Поиск работает по названию модели, идентификатору и приложению. Версии и квантизации остаются отдельными вариантами: выбор не подменяется первой моделью сервера. Профиль с тем же адресом и моделью используется повторно с сохранением приоритета и расписания.

LM Studio: `lms ls --json` возвращает скачанные модели даже при выключенном API. Embedding-модели из каталога не предлагаются для чата. Кнопка подключения запускает сервер через штатный CLI. Параметры конкретного варианта передаются в профиль.

Ollama: каталог читается через `/api/tags`, а при выключенном сервере — из локальных manifests с проверкой наличия слоёв в blobs. Учитывается `OLLAMA_MODELS`. Облачные модели отмечаются отдельно как требующие интернета. При выключенной Ollama подключение просит включить приложение.

Strata: используются установленные совместимые пакеты и модели работающего Desktop API. Пакеты запускаются только по кнопке, с прежней проверкой памяти. Пока идёт запуск, интерфейс сообщает об этом; после готовности нужно обновить список и нажать «Использовать». Настройки API и управления движком находятся в раскрываемом блоке. Ключ чужого API не читается с диска.

«Каталоги для скачивания» открывает официальные каталоги LM Studio/Ollama и проект Strata. Полные удалённые каталоги не копируются в Dewiar, загрузка весов выполняется самим приложением. После скачивания нужно обновить общий список.

Проверки: `tests/local_models_test.py`, `tests/local_models_ui_test.py`, `tests/local_installations_test.py`, `tests/strata_test.py`.

## Названия и дополнительные сведения

Заголовок показывает название из приложения, число параметров, формат и квантизацию. Рядом остаётся точный идентификатор подключения. «Подробнее о модели» раскрывает издателя, идентификатор каталога, архитектуру, возможности и контекст. Для LM Studio доступны сведения `lms ls --json` и, при работающем сервере, `/api/v1/models`. Для Ollama метаданные читаются через `/api/show` без запуска весов. Описания и лицензии показываются только при наличии в ответе приложения; исходные сведения не заменяются догадками по названию. Контекст модели и настройки загруженных экземпляров разделены. При недоступности API сохраняются сведения из локального каталога. Ссылка открывает страницу модели в официальном каталоге.

Кнопка «Открыть LM Studio / Ollama / Strata» запускает соответствующее приложение или переводит его окно на передний план. Она доступна у модели и в разделе каталогов. Это отдельное действие от подключения модели. На macOS используется штатный Launch Services (`open -a`) с фиксированным списком приложений; адреса и команды из интерфейса не исполняются. Если приложение не установлено, ошибка отображается в списке.

Кнопка «Использовать» явно включает ручной выбор: выбранный профиль становится активным, `llm.auto_select` выключается тем же сохранением. Это относится и к кнопкам Strata в дополнительных настройках. Для возврата к приоритетам и расписанию пользователь может снова включить автовыбор. Неуспешное подключение не меняет режим выбора.
